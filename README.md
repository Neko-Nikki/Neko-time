> *Every adventure begins with a curious cat.*

A **cat-themed Minecraft Java Edition survival server**, supported by The University of Tokyo(UTokyo) students, built on **Spigot**, combining RPG elements, an economy system, and a cozy multiplayer experience.

---

## 🐱 About

**Neko-time** is a community-driven Minecraft Java Edition server inspired by the spirit of cats—curious, adventurous, and always ready to explore.

Our goal is to create a friendly survival world where players can build, trade, battle, and discover new adventures together.

Whether you're collecting resources, opening a shop, or crafting legendary equipment, every day in **Neko-time** is another step into a world full of possibilities.

---

## ✨ Features

- 🐾 Cat-themed server identity
- 🌍 Spigot-powered server core
- 💰 Complete economy system
- 🛒 ChestShop trading
- 🔐 LuckPerms permission system
- 🗡️ RPGItems support
- 👤 SkinsRestorer integration
- 💬 EssentialsX Chat
- 📍 Spawn management
- ⚡ Performance optimization
- 📦 Modular plugin architecture
